## Immediate work

1. Publish project-specific documentation while preserving Dawn attribution.
2. Develop an editorial design system: colors, typography, imagery, spacing and accessibility rules.
3. Build the first custom Liquid section and open a documented feature PR.
4. Research inventory sourcing and unit economics before purchasing stock.
5. Establish QA and performance baselines, then add evidence as features ship.

## Evidence rules

A passing Theme Check is not a Core Web Vitals score. A configured analytics event is not automatically a verified event. A CRO hypothesis is not an improvement. Record sample size, audit conditions, dates, baseline and limitations for claims. Preserve representative screenshots and PR descriptions to make project ownership clear.
